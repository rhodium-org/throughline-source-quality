# throughline-source-quality

The quality bar for **throughline sources** — the standalone graphs that re-express a
published standard (ASVS, WCAG, AISVS, NIST AI RMF, MASVS, SLSA, …) so a consuming
project can compose them with
[throughline-compose](https://github.com/rhodium-org/throughline-compose).

Those sources are built by generators that read a publisher's machine-readable export
and emit one item per clause. This repository holds the requirements those generators
are built to meet, so that "the source is a faithful rendering of the standard" is a
thing that can be cited, reviewed and ratified rather than a thing each generator
re-decides on its own.

It carries
<!-- tl:count type == 'requirement' -->
7
<!-- tl:end --> requirements, published to [`docs/spec.md`](docs/spec.md).

## This graph is applied by construction, never by reference

**A governed source does not declare this graph as a `[[sources]]` dependency.** That
is [`NG-0001`](docs/spec.md#how-this-graph-is-applied), and it is a hard constraint
rather than a stylistic preference.

`tl-compose` namespaces are not transitive. If `throughline-asvs` adopted this graph
and cited `quality:REQ-0001` in an item link, then every project composing
`throughline-asvs` would have to declare a `quality` namespace of its own or fail:

```
tl-compose: reference 'quality:REQ-0001' names namespace 'quality',
            which is not a declared [[sources]] namespace
$ echo $?
2
```

Sources exist to be composed by other people. Loading them with the toolchain's own
housekeeping is a cost every consumer pays forever, for a requirement that is none of
their business.

So the linkage runs the other way, through construction:

| | |
|---|---|
| **What satisfies these requirements** | the generator that builds a governed source |
| **What cites them** | the commit that changes that generator |
| **What a governed source contains** | its standard, and nothing else |

A commit in a governed repository cites a requirement here by naming both the graph
and the UID — `throughline-source-quality REQ-0001` — because UIDs collide across
graphs and a bare `REQ-0001` is ambiguous.

## Status

Items authored with AI assistance carry `origin: hybrid` and are born `proposed`. The
graph's own gate refuses to let such an item reach `approved` without a human
ratifying it:

```
[ERROR] REQ-0001  unratified  hybrid-origin item awaiting human ratification
```

`tl check --strict` therefore stays red until a human has been through them. That is
the gate working, not a defect.

